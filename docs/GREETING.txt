
CleanWrap
Smart File Organizer for Windows
=====================

Version: v1.0
Developer: Ettisaf Rup
GitHub: https://github.com/ettisafxrup
___ ___ ___

CleanWrap automatically organizes messy folders into clean,
well-structured categories.
Simply run the application or right-click inside any folder and choose
	✨ Organize with CleanWrap
Your files will be sorted into categories such as:
Duplicate files are automatically detected and separated.

----------------------------------------------------------------------
Features
----------------------------------------------------------------------
• Intelligent file categorization
• Smart duplicate detection
• Automatic cleanup report
• Windows Context Menu integration
• Startup support
• Lightweight and portable
• No internet required
• Completely local processing
