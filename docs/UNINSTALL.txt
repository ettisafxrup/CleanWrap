======================================================================
Uninstalling CleanWrap
======================================================================

CleanWrap can be removed at any time.

Methods

1.

Control Panel

Programs and Features

Uninstall CleanWrap

or

2.

Settings

Apps

Installed Apps

CleanWrap

Uninstall

The uninstaller removes:

• Application files

• Context Menu entries

• Startup registration

It does NOT remove:

• Files organized by CleanWrap

• Your personal documents

• Cleanup logs
