Author:
    Ettisaf Rup (ettisafxrup)

Project:
    CleanWrap

Description:
    CleanWrap is a lightweight Windows utility written in Modern C++ that
    automatically organizes messy folders into clean, categorized
    directories. It intelligently classifies files, detects duplicates,
    generates cleanup reports, and helps keep your workspace tidy.

======================================================================
1. FEATURES
======================================================================

✔ Automatic File Organization

Files are sorted into dedicated folders based on their file extensions.

Supported Categories:

    • Images
    • PDFs
    • Videos
    • Audio
    • Code
    • Documents
    • ZIP / Archives
    • Executables & Installers
    • Others

Folders are created only when required.

----------------------------------------------------------------------

✔ Smart Duplicate Detection

Duplicate files are detected using:

    • 64-bit FNV-1a File Hashing
    • Windows duplicate filename patterns

Examples:

    File (1).pdf
    File (2).pdf
    Photo - Copy.png
    Report - Copy (3).docx

Detected duplicates are automatically moved into dedicated duplicate
folders inside their corresponding categories.

----------------------------------------------------------------------

✔ Cleanup Report

After every cleanup operation, CleanWrap generates

    _CleanWrap.log

The report contains

    • Date & Time
    • Files processed
    • Category statistics
    • Duplicate count
    • Error count

Logs are appended instead of overwritten.

----------------------------------------------------------------------

✔ Context Menu Integration

After installation, you can organize any folder instantly.

Simply:

    Open any folder

    Right Click on an EMPTY AREA

    Select

        Organize with CleanWrap

CleanWrap will organize the current folder without affecting files
outside that directory.

----------------------------------------------------------------------

✔ Startup Integration

If enabled during installation,

CleanWrap automatically runs every time Windows starts.

It silently organizes the Downloads folder and exits immediately.

No background processes remain running.

======================================================================
2. HOW TO USE
======================================================================

Method 1
---------

Double-click

    CleanWrap.exe

This organizes your Downloads folder.

----------------------------------------------------------------------

Method 2
---------

Right-click inside any folder

↓

Organize with CleanWrap

The selected folder will be organized.

----------------------------------------------------------------------

Method 3
---------

Restart Windows

If Startup Mode was enabled during installation,

CleanWrap automatically organizes Downloads once and exits.

======================================================================
3. DUPLICATE DETECTION
======================================================================

CleanWrap considers files duplicates only when

✓ File contents match (Hash Match)

AND

✓ Windows duplicate filename patterns are detected.

This prevents unrelated files with similar names from being moved.

======================================================================
6. NOTES
======================================================================

• Existing files are never overwritten.

• Duplicate filenames are automatically renamed when necessary.

• Empty category folders are not created.

• Empty duplicate folders are not created.

• The log file is ignored during organization.

• System folders are not modified.

======================================================================
7. PERFORMANCE
======================================================================

CleanWrap is written using

    Modern C++17/20
    STL
    std::filesystem

The application is lightweight, requires no runtime installation,
and performs all operations locally.

No internet connection is required.

======================================================================
8. TROUBLESHOOTING
======================================================================

Nothing happened?

• Make sure the selected folder contains supported files.

----------------------------------------------------------------------

Some files remained in Others?

• Their extensions are currently unsupported.

----------------------------------------------------------------------

Duplicate not detected?

• Duplicate detection compares actual file contents.
  Files with different content are treated as separate files.

----------------------------------------------------------------------

Accidentally organized the wrong folder?

• Files are only moved within the selected folder.
  Nothing outside that folder is modified.
